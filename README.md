# Predictive Analytics Using Historical Data

## Objective
Build a predictive analytics dashboard to forecast future sales trends using historical data.

## Tools Used
- Power BI
- Excel/CSV Dataset

## Features
- Data Cleaning
- KPI Cards
- Historical Sales Trend Analysis
- Sales Forecasting
- Interactive Slicers
- Business Insights

## KPIs
- Total Sales
- Average Sales
- Total Profit

## Outcome
Developed a predictive analytics dashboard that forecasts future sales and supports data-driven decision-making.
